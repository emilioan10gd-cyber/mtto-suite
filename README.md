# MTTO Suite

Sistema de Mantenimiento e Inventario Hospitalario

## Estructura

- **mtto/** - API Backend (.NET/C#)
- **mttoweb/** - Frontend (HTML/JavaScript)

## Áreas

- 🏥 Farmacia
- 🛠️ Almacén
- 🏥 Biomédico
- 💉 Catéter

## Despliegue

### Requisitos
- .NET Framework 4.7.2+
- SQL Server 2016+
- Node.js (para desarrollo)

### Instalación

```bash
# Backend
cd mtto
# Compilar en Visual Studio o con MSBuild

# Frontend
cd mttoweb
# Servir archivos HTML en IIS o servidor web
```
